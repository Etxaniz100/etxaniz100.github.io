Loop Escape

2D Rogue-like

Introduction

Loop Escape is a game I made as my Bachelor's Degree Final Project. It is a 2D rogue-like game where the player must advance through levels while defeating enemies and becoming stronger.

It was the first "big" game I made and it was quite the challenge. If all the coding side was not enough, I decided to do all the artwork for the game by myself, which was an added difficulty bonus.

About the game

In this game, your goal is to complete each level, defeating all enemies and upgrading your weapons by merging them. The weapons are not powerfull by themselves, the upgrades they have are applied to the main weapon, so you need to balance two weapons with updgrades that complement each other.

As my fist big project, I fell in the trap of overscoping, and many features were planned but not implemented. One of the features which interesed me the most was the procedural generation of levels, which finally was descarted due to time constraints. The levels are hand made but in the furute I would like to do some kind of procedural generation in another project. In this game, you play as a golem or construct, who needs to escape this cave system. Originaly there was some story planned but finally the narrative elements of the game were not added.

All this trial and error is documented in my Final Project Document.
