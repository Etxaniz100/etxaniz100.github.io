GAME DEVELOPMENT

HellStrings

Rhythm Game

Introduction

Hellstrings is a rithm game based on games like Guitar Hero, with a musical focus in classical music. This game was created for the 1 Bit Jam (7th edition) so it had the limit of only using two colors, hence the black and White palette. The Theme was "You are the enemy" and after some philosophical debate and some ideas changing through the days we ended up playing as a demon guitarrist who wants to transform angels into more demons, the better you perform, more people are converted. The team was formed by programmers, but we divided in different departments. All assets were made by three team members, including the music.

Technical Details

When you open the game, you can choose between two songs: Moonlight Sonata and Winter from Vivaldi's Four Seasons.

Each song has its own JSON file containing all the information required to play it:

Name The name of the song
Author The song's composer
BPM The song's tempo
Note Pattern A list whith info for each note. The beat in which they shoud be hit, and the rail in which they spawn

The JSON file is parsed by a script and converted into a C# class. The music controller then manages the flow of the game, controlling when each note spawns so that it reaches the hit point at the correct time.
