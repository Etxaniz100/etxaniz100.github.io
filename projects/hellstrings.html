HellStrings

Rithm Game

Introduction

Hellstrings is a rithm game based in games like Guitar Hero, with a musical focus in classical music. It was made for the Game Jam 1-bit so it had the limit of only using two colors, hence the black and White palette.The Theme was "You are the enemy" and after some phylosofical debate and some ideas changing through the days we ended up playing as a demon guitarrist who wants to transform angels into more demons, the better you perform, more people are converted. All assets where made by three teammembers, including the music. When you open the game, you can select between two songs, monlight sonata and winter from vivaldi's seasons. Each Song has a json file with all its info: Name, Author, BPM, Note patron

This game was originally created for the first 1 Bit Jam (7 edition) , Json partiture parsing Note flow controll Unity, C#Windows Made in 7 days 1 bit jam Team of 5-6 people
