GAME DEVELOPMENT

KirikiGo

2D Precision Platformer

Introduction

KirikiGo is a 2D precision platformer where you need to grab an apple to complete each level. You control a hedgehog who can transform into different animals to move through the terrain.

This game was originally created for the first Euskal Game Jam, a Game Jam organized in collaboration with the university UPV/EHU, with the goal of making games in Euskera, the language of the Basque Country.

You can also watch a playthrough here. This video was made by another contestant, and it really made my day.

While studying for my Master's degree, I remade the game using a custom engine in C++, based on the Raylib graphics library.
